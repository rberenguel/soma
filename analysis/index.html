Soma Cube Solution Analysis

The solver finds all 240 unique solutions, which are then grouped into unique structural classes based on their piece-adjacency graphs.

How are graph classes calculated?

To find the unique structural class for each graph, we compute a canonical label. This is a unique string that represents the graph's structure, regardless of how its pieces (vertices) are named.

Two solutions belong to the same class if their graphs are isomorphic—meaning they are structurally identical.

Our method is a brute-force approach suitable for small graphs:

  • We generate all 7! (5,040) possible permutations of the piece labels ('A' through 'G').
  • For each permutation, we create a new, relabeled version of the graph.
  • We then convert this relabeled graph into a unique string:
    • First, the graph's nodes (pieces) are sorted alphabetically (A, B, C...).
    • We iterate through the sorted nodes, building the string. For each node, we append its name, a colon, its alphabetically-sorted neighbors, and a semicolon.
    • This creates a segment like A:BCF; for a single node. The final string is a concatenation of all segments, e.g., A:BCF;B:ADG;....
  • The lexicographically smallest string found across all 5,040 permutations is chosen as the graph's official canonical label.

All isomorphic graphs will produce the exact same canonical label, allowing us to group them together.
